# Archive

Frozen earlier projects, kept for history. Nothing here is built, served or maintained: the studio's live
work is `motion/`, and the site links here only as a record. The files are kept exactly as they were, so their
own paths and instructions describe where they used to live, not this repository.

- `films/quokka-film-original/` — the first code-drawn film's original project (built 2026-09-24 in the rotli
  repo's ignored `marketing/`, moved to the studio the same day). `motion/` is canonical; the sealed golden
  `rotliStory` was recorded from this project's render, and `motion/out/video/rotli-story.mp4` matches it.
- `films/launch-film/` — the 79-second launch promo and 15-second teaser: the HyperFrames edit
  (`hyperframes/`) and the older Remotion cut (`src/`); `launch-film/HYPERFRAMES.md` is the creative and audit
  record. **Not runnable as is:** its scripts resolve the product checkout and footage relative to their old
  home (`marketing/` in the rotli repo), and the source footage never left that machine's ignored folders.
  Treat it as a record of how the promo was made, not a tool.

The published promo lives on rotli.co. Media renders inside these folders are gitignored.
