# Linen (the studio theme)

**Prompt.** Music for browsing Rotli's studio: very calm and simple, something you can leave on while
reading and stop noticing. It should sound like the films, only quieter: the same I-IV-I-V | I-IV-V-I
phrase and the same music-box melody, slowed down and thinned out. No drums, no build, no hook that
demands attention. Warm pad chords, a soft root on each downbeat, two melody notes per bar (the second
pass an octave lower and a half-beat later, like an echo), a small room around it. About a minute, and it
must loop with no seam.

**Spec.** C major, 66 bpm, 16 bars (about 58 s). Pad: detuned sine + triangle, 1.6 s attack. Melody: a
sine with two partials (music box). Reverb 32%. Peak -9 dBFS. The tail is folded onto the start so the
loop point is silent-free and seamless.

**Plays.** Only when sound is turned on in the top bar; it fades out whenever a film plays with sound
and back in when the film stops.
